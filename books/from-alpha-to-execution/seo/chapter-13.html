13.1.3 Hot Path และ Cold Path
การออกแบบที่ใช้งานจริงควรแยกเส้นทางที่มีผลต่อการตัดสินใจทันทีออกจากงานสนับสนุน
• Hot path: receive, decode, book update, feature update, signal, inline risk, order
  encoding และ transmit
• Cold/asynchronous path: logging แบบหนัก, dashboard, การวินิจฉัย ตัว แบบ, historical
  persistence, report, deep analytics และ non-critical reconciliation
          หลักการนีไ้ ม่ได้หมายความว่า cold path “ไม่สำคัญ” แต่หมายถึงไม่ควรให้ I/O หรือ allocation
ที่ไม่จำเป็นบน hot path กลายเป็นแหล่ง jitter โดยไม่ตั้งใจ

 13.18 แบบฝึกหัดและโจทย์วิจัย
 1. อธิบายความแตกต่างระหว่าง latency, jitter, throughput และ utilization พร้อมยกตัวอย่างว่า
    ระบบที่ throughput สูงยังมี tail latency แย่ได้อย่างไร
 2. จาก service rate µ = 300,000 events/ s และ arrival rate λ ∈
    {120,000, 240,000, 285,000} events/ s จง คำนวณ utilization และ อภิปราย
    sensitivity ของ queueing ต่อ ρ ใกล้หนึ่ง
 3. ภายใต้ M /G/1 ถ้า λ = 100,000/s, E[S] = 5 µs และ E[S 2 ] = 40 × 10−12
    s2 จงคำนวณ ρ และ E[Wq ] พร้อมอภิปรายข้อจำกัดของสมมติฐาน Poisson
 4. พิสูจน์ ว่า Q0.99 (X + Y ) ไม่ จำเป็น ต้องเท่ากับ Q0.99 (X) + Q0.99 (Y ) โดยสร้าง
    counterexample อย่างง่าย
 5. ให้ stage latency มี covariance matrix ที่ กำหนด จงคำนวณ Var(Ltotal ) และเปรียบเทียบกับ
    กรณีสมมติ independence
 6. สัญญาณมี α0 = 10 bps, cost+risk buffer = 4 bps และ τα = 3 ms จงหา Lmax และ
    retained alpha เมื่อ L = 0.5, 1, 3, 5 ms
 7. ออกแบบ staleness gate ที่ ใช้ market-data age, ความเชื่อ มั่น ของตัว แบบ และ expected net
    edge พร้อมอธิบายกรณีที่ควร reject แม้ raw alpha สูง
 8. ออกแบบ sequence-gap recovery สำหรับ multicast market data ทีม่ ี snapshot channel แยก
    โดยระบุ state transition ตั้งแต่ healthy ไป recovery และกลับ healthy
 9. ให้ clock error ของ host A และ B bounded ที่ 20 และ 35 µs จงหาขอบเขตสูงสุดของ error
    ใน one-way latency ที่คำนวณจากสองนาฬิกา
10. ข้อความมีขนาด 1,200 bytes บน link 10 Gbps จงคำนวณ serialization delay โดยไม่นับ framing
    overhead และเปรียบเทียบกับ propagation 2 km ใน fiber จาก v = 2 × 108 m/s
11. ออกแบบ order-state accounting invariant สำหรับ new, partial fill, cancel และ reject แล้ว
    เสนอ unit tests ที่ boundary cases
