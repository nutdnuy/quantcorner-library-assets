คำนำ


หนังสือเล่มนี้ถูกออกแบบใหม่จากฐานองค์ความรู้สองสายที่เดิมมักถูกแยกออกจากกัน ได้แก่ การวิเคราะห์หลักทรัพย์เชิงเทคนิคและกลยุทธ์การลงทุน กับการวิจัยอัลฟาและการสร้างพอร์ตการลงทุนเชิงระบบ เป้าหมายคือการตอบคำถามที่สำคัญกว่า “สัญญาณไหนดี” นั่นคือ จะเปลี่ยนสารสนเทศให้เป็นอัลฟา เปลี่ยนอัลฟาให้เป็นสถานะลงทุน และเปลี่ยนสถานะลงทุนให้เป็นคำสั่งซื้อขายที่ดำเนินการได้จริงภายใต้ต้นทุน ความเสี่ยง สภาพคล่อง และข้อจำกัดของตลาดอย่างไร


แกนกลางของหนังสือคือห่วงโซ่

Data→Feature→Alpha→Portfolio→Order→Execution→Risk→Learning

เนื้อหาเดิมเกี่ยวกับค่าเฉลี่ยเคลื่อนที่ MACD, RSI, Bollinger Bands, แท่งเทียน กลยุทธ์โมเมนตัม และการทดสอบย้อนหลังถูกยกระดับจาก “เครื่องมือดูกราฟ” ให้เป็นคุณลักษณะ (features) และสมมติฐานเชิงสถิติที่ต้องทดสอบ ส่วนเนื้อหาอัลฟาเดิมถูกต่อยอดไปสู่โครงสร้างจุลภาคของตลาด สมุดคำสั่ง การส่งคำสั่งซื้อขาย ต้นทุน ผลกระทบต่อตลาด สถาปัตยกรรม HFT การควบคุมความเสี่ยงก่อนส่งคำสั่ง และระบบ production


หนังสือใช้รูปแบบซ้ำในทุกบทคือ Theory → Mathematics → Algorithm → Code → Experiment → Trading Lab → Failure Case → Checklist เพื่อให้ผู้อ่านเชื่อมทฤษฎีกับการปฏิบัติได้จริง และสร้างผลงานที่ตรวจสอบซ้ำได้
