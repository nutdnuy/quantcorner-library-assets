C.4.4 สะพานจากงานวิจัยของผู้เขียนสู่ Expression Engineering
ฐานงานวิจัยของผู้เขียนช่วยให้เห็นว่า “operator” ที่ดีไม่ควรถูกเลือกเพราะรูปลักษณ์ของสูตรเพียงอย่าง
เดียว งาน MACDP ร่วมกับ fuzzy trading weight แสดงแนวคิดสำคัญสองชั้น คือ การลดความล่าช้าของ
สัญญาณและการแปลงความเชื่อมั่นให้เป็นน้ำหนักการตัดสินใจ แทนการบังคับให้ทุกสัญญาณเป็น buy/
sell แบบทวิภาค Boonprasurt et al. (2022) ในภาษาของภาคผนวกนี้ หลัก คิด ดัง กล่าวสอดคล้องกับ
การแยก core expression ออกจาก confidence/gating layer เพื่อ ให้ ตรวจสอบได้ ว่า คุณค่า มาจาก
สารสนเทศของสัญญาณหรือจากการปรับขนาดสถานะ
         อีก ด้านหนึ่ง งานทดสอบ Bollinger Bands กับ ค่า เฉลี่ย เคลื่อนที่ หลายชนิด บน SET50 ใช้ การ
ประเมิน out-of-sample การรวมต้นทุนธุรกรรม การตรวจความไวของพารามิเตอร์ bootstrap และการ
ควบคุม multiple testing ด้วย FDR Witayakiattilerd and Panichkitkosolkul (2026) สิ่งที่ถ่ายโอน
มาสู่ Fast Expression จึงไม่ใช่ข้อสรุปว่า operator ใดดีที่สุดตลอดไป แต่เป็น ระเบียบวิธี: นิพจน์ทุกตัว
ต้องผ่าน

C.8 การถ่ายโอนแนวคิดไปยัง Python
การถ่ายโอนที่ ถูก ต้องต้องรักษา semantics ไม่ใช่ แปลชื่อ operator แบบตัว ต่อ ตัว ตัวอย่าง pseudo-
Python ที่รักษา horizon และ rank convention ของสมการข้างต้นคือ
def reversal_alpha(close, h, m, eps):
   ret_h = close / close.shift(h) − 1.0
   sigma_h = ret_h.rolling(m, min_periods=m).std(ddof=1)
   raw = −ret_h / (sigma_h + eps)

   r = raw.rank(axis=1, method="average", na_option="keep")
   n = raw.notna().sum(axis=1)
   rank01 = r.sub(1.0).div(n.sub(1.0), axis=0)
   rank01 = rank01.where(n.gt(1), other=float("nan"), axis=0)
   return 2.0 * rank01 − 1.0

ในตัวอย่างนี้ สมมติ ว่า แถวเป็น เวลาและคอลัมน์ เป็น สินทรัพย์ จึง ใช้ axis=1 สำหรับ cross-sectional
rank การใช้ rank(pct=True) โดยตรงไม่ เท่ากับ สมการ (C.9) เพราะให้ สเกลประมาณ 1/N, . . . , 1
และยังไม่ทำ centering เป็น [−1, 1] ตัวอย่างนี้ยังไม่ production-ready เพราะต้องระบุ universe,
missing data, corporate actions, calendar, point-in-time membership, tie behavior และ
signal availability

C.9 Failure Cases ที่พบบ่อย
1. Look-ahead by field semantics: สูตรย้อนหลังแต่ field ยังไม่ทราบจริง ณ เวลา t
2. Universe leakage: rank บนรายชื่อหุ้นที่คัดด้วยข้อมูลอนาคต
3. Unit mismatch: นำราคา absolute ไปเทียบข้ามหุ้นโดยไม่ normalize
4. Operator stacking: เพิ่ม rank/decay/gate หลายชั้นจน economic mechanism หาย
5. Multiple testing blindness: เลือกสูตรดีที่สุดจาก search ใหญ่แต่รายงานเพียงผลตัวชนะ
6. Turnover explosion: IC ดีขึ้นเล็กน้อยแต่ turnover/cost เพิ่มมากกว่า edge
7. Neutralization without audit: factor exposure ลดแต่ liquidity/sector concentration แย่
   ลง
8. Research–execution confusion: ถือว่า expression output เป็น order size โดยตรง
