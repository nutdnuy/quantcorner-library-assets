เริ่มจัดพอร์ตจากสินทรัพย์สองตัว

ถ้าหุ้น A ผันผวน 20% และสินทรัพย์ B ผันผวน 10% การแบ่งเงินลงทุนจะทำให้พอร์ตผันผวนเท่าไร?

คำตอบขึ้นอยู่กับทั้งสัดส่วนเงินที่ใส่และการเคลื่อนไหวของสินทรัพย์สองตัวในช่วงเดียวกัน เราจะเริ่มจากเงิน 10,000 บาท คำนวณผลตอบแทนเป็นบาทก่อน แล้วค่อยดูว่าทำไมการนำความผันผวนมาเฉลี่ยตรง ๆ จึงมักไม่ตรงกับความผันผวนของพอร์ต

เนื้อหานี้เรียบเรียงประกอบหัวข้อการกระจายการลงทุนและ Lab 107–108 ตัวเลขทั้งหมดเป็นตัวอย่างสมมติ โค้ดสร้างข้อมูลเองและรันได้โดยไม่ใช้ CSV ของคอร์ส อ่านพื้นฐานผลตอบแทนและ Python ก่อนหากยังไม่คุ้นกับตัวแปร Series และ DataFrame

ตัวอย่างช่วงแรกใช้ผลตอบแทนรายเดือนที่เกิดขึ้นแล้วในสถานการณ์สมมติ ส่วนช่วงท้ายใช้ expected return และ covariance ต่อปีที่ตั้งเป็นข้อมูลเข้าแบบจำลอง เราจะแยกชื่อชุดข้อมูลให้ชัด และไม่ถือว่าค่าเฉลี่ยจากข้อมูลไม่กี่เดือนเป็นผลตอบแทนในอนาคตที่ทราบแน่นอน

สมมติว่ามีเงิน 10,000 บาท ซื้อ A มูลค่า 6,000 บาทและ B มูลค่า 4,000 บาท น้ำหนักของ A คือ wA=6,000/10,000=0.6w_A=6{,}000/10{,}000=0.6wA​=6,000/10,000=0.6 และน้ำหนักของ B คือ wB=0.4w_B=0.4wB​=0.4 ตัว www ย่อจาก weight หน่วยเป็นสัดส่วนของมูลค่าพอร์ต ไม่ใช่จำนวนหุ้น

ถ้า A ราคาหุ้นละ 200 บาทและ B หุ้นละ 20 บาท เราจะถือ A 30 หุ้นและ B 200 หุ้น จำนวนหุ้น B มากกว่าไม่ได้แปลว่ามีน้ำหนักมากกว่า ต้องคูณจำนวนหุ้นด้วยราคาก่อนแล้วจึงเทียบมูลค่า

สินทรัพย์ เงินลงทุนต้นเดือน น้ำหนัก ผลตอบแทนเดือนนั้น มูลค่าปลายเดือน

import numpy as np
import pandas as pd

start_values = pd.Series({"A": 6000.0, "B": 4000.0})
one_month = pd.Series({"A": 0.10, "B": -0.05})
weights = start_values / start_values.sum()
end_values = start_values * (1 + one_month)
portfolio_return = (weights * one_month).sum()
print(f"Portfolio return: {portfolio_return:.2%}")
print(f"End value: {end_values.sum():,.2f}")

monthly = pd.DataFrame({
    "A": [0.02, 0.04, -0.02, 0.00],
    "B": [0.01, 0.00, 0.03, 0.00]

print((monthly_portfolio * 100).round(2))

เก็บสูตรไว้ในฟังก์ชันด้วย def ส่วน return ส่งผลลัพธ์กลับให้ผู้เรียก ตัวแปร weight_a เป็นน้ำหนักของ A แล้วน้ำหนัก B เท่ากับ 1 - weight_a

mu_a, mu_b = 0.08, 0.04
sigma_a, sigma_b, rho_ab = 0.20, 0.10, 0.25

def two_asset_metrics(weight_a):
    weight_b = 1 - weight_a
    expected = weight_a * mu_a + weight_b * mu_b
    variance = (weight_a * sigma_a) ** 2 + (weight_b * sigma_b) ** 2
    variance += 2 * weight_a * weight_b * rho_ab * sigma_a * sigma_b
    return expected, np.sqrt(variance)

print(two_asset_metrics(0.60))
