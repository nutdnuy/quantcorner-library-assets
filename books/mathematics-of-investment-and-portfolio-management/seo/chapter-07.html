7.2.1       ข้อสมมติและขอบเขตของกรอบ Mean–Variance
กรอบ mean–variance ใช้ expected return เป็นตัวแทน reward และ variance เป็นตัวแทน risk เกณฑ์นี้มี
ฐานเชิงทฤษฎีที่ชัดเจนภายใต้ quadratic utility และมีความสะดวกมากเมื่อผลตอบแทนอยู่ในตระกูลการแจกแจง
ที่อธิบายได้ดีด้วยพารามิเตอร์ตำแหน่งและการกระจาย เช่น กรณีปกติ อย่างไรก็ตาม ในข้อมูลจริงที่มี skewness,
fat tails หรือ downside asymmetry การใช้เพียงสองโมเมนต์แรกอาจไม่สะท้อนความเสี่ยงทั้งหมด จึงควรมอง
mean–variance เป็นแบบจำลองอ้างอิงที่มีประโยชน์ ไม่ใช่คำอธิบายความเสี่ยงที่สมบูรณ์ในทุกสถานการณ์

universe, short-sale rule, leverage rule และข้อจำกัดด้านสภาพคล่อง เพราะการเปลี่ยนองค์ประกอบใดองค์
ประกอบหนึ่งสามารถเปลี่ยน feasible set และ efficient frontier ได้ แม้ข้อมูลราคาชุดเดิมจะไม่เปลี่ยน

   19. พิสูจน์ว่าเมื่อ feasible set ถูกทำให้เล็กลง minimum variance ที่ target เดิมไม่สามารถลดลง
   20. อธิบายด้วย eigendecomposition ว่า เหตุ ใด covariance matrix ที่ ill-conditioned ทำให้ น้ำ หนัก
       optimizer ไม่เสถียร
   21. ออกแบบ sensitivity experiment โดย perturb expected return ของสินทรัพย์หนึ่งตัว ±50 bp
   22. เปรียบเทียบ sample covariance กับ shrinkage covariance ในแง่ frontier และ weight stability
   23. ออกแบบ rolling out-of-sample experiment ที่ไม่มี look-ahead bias
   24. อธิบายความแตกต่างระหว่าง in-sample efficient portfolio กับ realized best portfolio
   25. อธิบายว่าเหตุใดการเพิ่ม risk-free asset ในบทถัดไปทำให้ปัญหา efficient portfolio เปลี่ยนจากเส้นโค้ง
       ไปสู่การหาเส้นสัมผัส

    1. พอร์ตที่อยู่บน efficient frontier จำเป็นต้องเป็นพอร์ตที่ดีสำหรับนักลงทุนทุกคนหรือไม่
    2. เหตุใด expected-return estimation error จึงสร้างน้ำหนักสุดโต่งได้ง่าย
    3. constraints ที่ทำให้ in-sample frontier แย่ลงอาจทำให้ผลจริงดีขึ้นได้อย่างไร
    4. หาก covariance matrix มี ความแม่นยำสูง แต่ expected returns แทบพยากรณ์ ไม่ ได้ ควรออกแบบ
       พอร์ตอย่างไร
    5. การใช้ historical efficient frontier เพื่อสื่อสารกับนักลงทุนควรมีคำเตือนหรือ uncertainty information
       แบบใด
    6. Markowitz theory ควรถูก มองเป็น “คำตอบสุดท้าย” หรือ เป็น mathematical benchmark สำหรับ
       การพัฒนาระบบบริหารพอร์ตที่ซับซ้อนขึ้น
